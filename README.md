# Эрудит

Android-приложение для развития общей эрудиции и мышления: большая офлайн-библиотека уроков по десяткам областей знания, экзамены по ступеням, интервальные повторения и тренажёры интеллекта.

## Возможности

- **Курсы со ступенями.** Область → курс → три ступени (основы, углубление, продвинутый уровень) → уроки. Каждая ступень завершается экзаменом, курс — итоговым экзаменом, область — большим экзаменом.
- **Уроки** с ключевыми идеями, фактами, таблицами и формулами; после урока — проверка по всем его вопросам.
- **Ответы вводятся с клавиатуры.** Проверка прощает регистр, опечатки, формы слов и числа словами («сорок» = 40) и сравнивает ответ с неверными вариантами. Если ответ верный, но сформулирован иначе, его можно засчитать кнопкой «Я ответил правильно». На экзаменах подсказок нет: засчитать ответы можно в разборе ошибок, и результат экзамена (процент, сдача, бонус) пересчитается.
- **Интервальные повторения** (упрощённый SM-2): все вопросы пройденных уроков возвращаются по кривой забывания.
- **Практика:** смешанная тренировка, работа над ошибками, блиц на 90 секунд с короткими ответами, тренировка по области/курсу/уроку.
- **Тренажёры интеллекта:** устный счёт, числовые ряды, логические задачи, запоминание цифр, N-back, таблица Шульте, тест Струпа.
- **Флаги мира и столицы мира:** 194 страны (члены ООН и Ватикан), упорядоченные по известности. Пользователь задаёт число стран, и для каждого числа ведётся свой рекорд.
- **Мотивация:** цель дня, серии, уровни и опыт, 35 достижений, статистика активности и точности, слабые места.
- **Обновления из приложения:** при запуске приложение сверяется с GitHub Releases и, если вышла новая сборка, показывает окно со списком изменений; APK скачивается и устанавливается прямо оттуда. Раздел «Что нового» CI собирает из сообщений коммитов с предыдущей сборки.
- **Опыт только за новое:** первое прохождение урока, первый верный ответ на вопрос, повторение, срок которого наступил, первая сдача экзамена. Тренажёр приносит опыт раз в день — по лучшему результату дня; более сильная тренировка добавляет только разницу.
- Светлая и тёмная тема, настройка размера текста, ежедневные напоминания, поиск, закладки.

## Установка

Готовые APK публикуются в разделе **Releases** после каждого push (GitHub Actions); свежая сборка всегда доступна по ссылке `releases/latest`. В описании каждого релиза указан отпечаток ключа подписи: сборки с одинаковым отпечатком ставятся поверх друг друга без потери прогресса.

Без секретов подписи CI создаёт свой ключ при первой сборке и хранит его в кэше Actions. Кэш привязан к ветке, а GitHub удаляет его, если неделю не было сборок. Тогда появится новый ключ, и приложение придётся переустановить. Для постоянного ключа добавьте в секреты репозитория `SIGNING_KEYSTORE_BASE64` (keystore в base64), `SIGNING_STORE_PASSWORD`, `SIGNING_KEY_ALIAS`, `SIGNING_KEY_PASSWORD`.

## Сборка

```
./gradlew :app:assembleRelease          # APK: app/build/outputs/apk/release/
./gradlew :app:testDebugUnitTest --tests 'app.erudit.ContentValidationTest'   # проверка контента
./gradlew :app:testDebugUnitTest --tests app.erudit.ScreenshotTest           # PNG экранов в app/build/screenshots
```

Нужны JDK 17+ и Android SDK 35.

## Формат контента

Контент лежит в `app/src/main/assets/content/`: папка на область (`01-math/`) с `domain.txt` и файлами курсов (`01-numbers.txt`). Числовой префикс задаёт порядок.

```
title: Название курса
description: Описание

@stage Основы
@lesson lesson-id
title: Название урока
minutes: 7

Текст урока. ## заголовок, **жирный**, *курсив*, списки «- », таблицы «| a | b |»,
«> ключевая мысль», «!> интересный факт», «$$ формула».

? Вопрос
+ верный ответ
- неверный ответ
= пояснение
?! Экзаменационный вариант: та же задача на другом примере
+ верный ответ
- неверный ответ
= пояснение
```

Вопросы-задачи (вычисления, применение правила или понятия к примеру) получают экзаменационные варианты «?! » сразу после вопроса урока. На экзамене вместо такого вопроса задаётся один из его вариантов, чтобы проверялось понимание, а не память на ответ из проверки урока. Вопросы на факты вариантов не имеют и на экзамене задаются как есть.

Ответ вводится с клавиатуры. Если без вариантов вопрос не имеет смысла («Какое число делится на 9?», «Что ближе по времени…»), его начинают с «?? » (экзаменационный вариант — с «??! ») — тогда варианты показываются и можно ввести букву. То же происходит само для формулировок «из перечисленного», «какое из…».

Логические задачи для тренажёра — `content/logic.txt` в том же формате вопросов. `ContentValidationTest` проверяет структуру, уникальность и полноту вопросов.

Kotlin, Jetpack Compose (Material 3), Navigation Compose, Room, DataStore, WorkManager. Шрифт Literata (SIL OFL). Изображения флагов — flagcdn.com (флаги из Википедии, общественное достояние), лежат в `assets/flags`.
